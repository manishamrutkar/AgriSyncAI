# 🌾 AgriSync AI

AgriSync AI is an AI-powered smart agriculture platform designed to optimize crop allocation, improve farming efficiency, and support sustainable agriculture in India.

---

# 🚀 Features

- AI Crop Recommendation
- Agricultural Analytics Dashboard
- Weather Intelligence
- AI Farming Assistant Chatbot
- JWT Authentication
- PDF Report Export
- Responsive SaaS UI
- Dockerized Microservices
- CI/CD Pipeline

---

# 🛠 Tech Stack
